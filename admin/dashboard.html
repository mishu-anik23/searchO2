Queries Express server on /api. When hosted on searcho2.online, requires reverse-proxy to Node service.

🌐 How to connect searcho2.online to live Express backend:

  1. Option A (Cloudflare Worker Proxy): Set up a Cloudflare Worker on route searcho2.online/api/* to reverse-proxy requests to your deployed backend (e.g. Render/Railway).
  2. Option B (Subdomain api.searcho2.online): Point a DNS record api.searcho2.online directly to your backend host.
  3. Option C (Local Dev Backend): Start backend locally with npm run dev and enter http://localhost:5000/api above!
