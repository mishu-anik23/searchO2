## What is included

### Farm (vanilla SPA)
- Open `index.html` or `npm run farm`
- Strict chapter/mission adapter (Ch1: Start Your Farm)
- Plot 1 only in Ch1; pond Ch4; garden Ch3; garage after storage+road; wind Ch5 + engineer
- Chapter intro briefing (+5 XP acknowledgment)
- Clear locked-task reasons (e.g. Needs Digging Equipment)

### OxyForge (Vite / React)
```bash
npm install
npm run dev
```
- Mission HQ with Moon → Mars path and Sky lab
- Sticky launch-pad countdown (small screens)
- 3D Pad3D, FPV with public satellites, deep-sky constellations
- Zodiac / natal chart (Sky lab)
- Mars landing + surface plant + Mars civ v2 (why → library → field → RXP)
- Lunar / Mars explorers
