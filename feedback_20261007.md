**Chapter activation rule**

This should be strict:

Current Chapter = 1

Chapter 1 story missions → ACTIVE

Chapter 1 optional challenges → contextual

Chapter 1 world events → contextual

Chapter 2 → PREVIEW ONLY

Chapter 3–8 → LOCKED / ROADMAP ONLY

A later system may exist technically in code, but:

**existence ≠ availability ≠ visibility ≠ activation**

Those must be four separate concepts.

Chapter 5 energy code can exist.

canTriggerEvents = false

canGenerateTasks = false
